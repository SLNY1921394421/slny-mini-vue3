# 🎯 所有知识点 **一句话总结**

## 07 effect runner

`effect()` 返回一个**手动执行函数**，`runner()` 直接执行回调。

## 08 effect scheduler

**控制更新时机**，trigger 不直接 run，而是执行 scheduler。

## 09 stop

从所有 dep 中**删除自己**，不再响应式。

## 10 readonly

Proxy 拦截 set，**只读不修改**。

## 11 isReactive / isReadonly

通过内部 `__v_isReactive` / `__v_isReadonly` 判断。

## 13 嵌套对象

**get 时递归 reactive/readonly**（懒代理）。

## 14 shallowReadonly

**只代理第一层，不递归**。

## 15 isProxy

判断是否 reactive 或 readonly。

## 16 ref

基础类型用 **class + getter/setter** 实现响应式。

## 17 isRef / unref

判断 ref + 自动解包。

## 18 proxyRefs

对象中 ref **自动 .value**。

## 19 computed

**缓存 + 懒执行**，依赖变化标记 dirty，取值才计算。

## 1. `ReactiveEffect` 类（副作用载体）

### 🔥 **原理**

- 每调用一次 `effect(fn)`，就创建一个 **`ReactiveEffect` 实例**
- 负责：**执行函数、收集依赖、触发更新、停止、调度**

### 完整代码 + 逐行精讲

```
export class ReactiveEffect {
  // 用户传入的回调函数
  private _fn: () => void

  // 调度器：控制更新时机（computed / watch 核心）
  public scheduler: () => void

  // 是否激活：false = 已 stop，不再响应式
  public active = true

  // 保存该 effect 被哪些 dep 收集（stop 清空用）
  public deps: Set<ReactiveEffect>[] = []

  constructor(fn: () => void, scheduler?: () => void) {
    this._fn = fn
    this.scheduler = scheduler
  }

  // 执行副作用（核心方法）
  run() {
    // 已 stop → 只执行函数，不收集依赖
    if (!this.active) {
      return this._fn()
    }

    // 标记当前 effect → 让 track 能收集到
    activeEffect = this
    shouldTrack = true

    // 执行 fn → 触发 proxy get → 自动收集依赖
    const res = this._fn()

    // 执行完清空，防止误收集
    activeEffect = null

    return res
  }

  // 停止 effect（从所有依赖中删除自己）
  stop() {
    if (this.active) {
      cleanupEffect(this)
      this.active = false
    }
  }
}
```

  object,
  Map<string | symbol, Set<ReactiveEffect>>
>()
```

## 3. `track` 依赖收集（get 时调用）

### 🔥 **原理**

读取响应式数据时，**把当前 effect 存入依赖桶**

```
export function track(target: object, key: string | symbol) {
  // 不在收集状态 → 退出
  if (!isTracking()) return

  // 1. 获取对象的依赖 Map
  let depsMap = targetMap.get(target)
  if (!depsMap) {
    depsMap = new Map()
    targetMap.set(target, depsMap)
  }

  // 2. 获取属性的依赖集合
  let dep = depsMap.get(key)
  if (!dep) {
    dep = new Set()
    depsMap.set(key, dep)
  }

  // 3. 真正收集
  trackEffects(dep)
}

// 把 effect 加入 dep
export function trackEffects(dep) {
  if (dep.has(activeEffect)) return
  dep.add(activeEffect)
  activeEffect.deps.push(dep) // 双向记录
}
```

------

## 4. `trigger` 触发更新（set 时调用）

### 🔥 **原理**

修改数据时，**把依赖桶里的 effect 全部执行**

```
export function trigger(target: object, key: string | symbol) {
  let depsMap = targetMap.get(target)
  if (!depsMap) return

  let dep = depsMap.get(key)
  triggerEffect(dep)
}

// 遍历执行所有 effect
export function triggerEffect(dep) {
  if (!dep) return

  for (const effect of dep) {
    if (effect.active) {
      // 有调度器 → 执行调度器（computed 核心）
      if (effect.scheduler) {
        effect.scheduler()
      } else {
        effect.run()
      }
    }
  }
}
```

## 5. `cleanupEffect` 清理依赖（stop 核心）

### 🔥 **原理**

从所有 dep 中删除自己，**不再响应更新**

```
export function cleanupEffect(effect: ReactiveEffect) {
  effect.deps.forEach(dep => {
    dep.delete(effect)
  })
  effect.deps.length = 0
}
```

## 6. `effect` 入口函数（对外 API）

### 🔥 **原理**

- 创建副作用
- **返回 runner 手动执行**
- 默认执行一次，收集依赖

```
export function effect(fn: () => void, options: any = {}) {
  const _effect = new ReactiveEffect(fn)

  // ✅ 07 effect 返回 runner
  const runner = _effect.run.bind(_effect)
  runner.effect = _effect

  // 首次执行，收集依赖
  _effect.run()

  return runner
}
```

## 7. `stop` 停止函数

### 🔥 **原理**

停止响应式，不再更新

```
export function stop(runner: any) {
  runner.effect.stop()
}
```

# 二、`baseHandler.ts` 详解（Proxy 处理器）

## 1. `createGetter` 高阶函数（生成 get）

### 🔥 **原理**

- 读 → **track 收集依赖**
- 嵌套对象 → **递归 reactive/readonly**
- 只读 → **不收集、不允许修改**
- 浅层 → **不递归**

```
function createGetter(isReadOnly = false, shallow = false) {
  return function get(target, key, receiver) {
    // ✅ 11 isReactive / isReadonly 内部标记
    if (key === ReactiveFlag.IS_REACTIVE) {
      return !isReadOnly
    }
    if (key === ReactiveFlag.IS_READONLY) {
      return isReadOnly
    }
    // 获取原始对象
    if (key === ReactiveFlag.RAW) {
      return target
    }

    const res = Reflect.get(target, key, receiver)

    // ✅ 非只读才收集依赖
    if (!isReadOnly) {
      track(target, key)
    }

    // ✅ 14 shallowReadonly 直接返回，不递归
    if (shallow) return res

    // ✅ 13 嵌套对象：递归转为响应式
    if (isObject(res)) {
      return isReadOnly ? readonly(res) : reactive(res)
    }

    return res
  }
}
```

// ✅ 11 isReactive
export function isReactive(value) {
  if (!value) return false
  if (value[ReactiveFlag.IS_READONLY]) {
    return isReactive(value[ReactiveFlag.RAW])
  }
  return !!value[ReactiveFlag.IS_REACTIVE]
}

// ✅ 11 isReadonly
export function isReadonly(value) {
  return !!value[ReactiveFlag.IS_READONLY]
}

// ✅ 15 isProxy
export function isProxy(value) {
  return isReactive(value) || isReadonly(value)
}
```

# 四、`computed.ts` 详解（带缓存的 effect）

## 🔥 **原理（最重要）**

1. **computed = 懒执行 + 缓存 effect**
2. 依赖不变 → **直接返回缓存**
3. 依赖变化 → **标记 dirty**
4. 取值时才计算

## 完整代码 + 逐行精讲

```
import { ReactiveEffect } from "./effect"

class ComputedRefImpl {
  private _getter: any
  private _effect: ReactiveEffect
  private dirty: boolean = true // 脏标记
  private _value: any // 缓存值

  constructor(getter) {
    this._getter = getter

    // ✅ 创建 effect，依赖变化时标记 dirty
    this._effect = new ReactiveEffect(getter, () => {
      if (!this.dirty) {
        this.dirty = true
      }
    })
  }

  get value() {
    // ✅ 脏 → 重新计算
    if (this.dirty) {
      this.dirty = false
      this._value = this._effect.run()
    }
    // ✅ 不脏 → 直接返回缓存
    return this._value
  }
}

export function computed(getter) {
  return new ComputedRefImpl(getter)
}
```

# 🎯 10 秒终极总结（背会这一页就够了）

1. **reactive**：Proxy 代理对象，get 收集、set 触发
2. **effect**：副作用载体，可 runner、scheduler、stop
3. **readonly**：只读代理，不能 set
4. **ref**：包装基础类型，class getter/setter 响应式
5. **computed**：缓存 + 懒执行 + 依赖追踪
6. **proxyRefs**：自动解包，不用 .value
